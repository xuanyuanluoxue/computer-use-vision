# 实战示例：把桌面文件移动到 D:\ 根目录（纯模拟操作）

> 2026-08-05 实测记录。目标：不执行任何文件命令，完全用"截图识图 + 模拟点击"完成移动。

## 前置

- 已配置识图 Key（见 SKILL.md）
- 文件资源管理器已打开一个窗口（本例：`D:\Github\claude-vision-skill`）

## 流程

### 第 1 步：看桌面，列出内容

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/see.ps1 -WindowTitle "文件资源管理器" -Prompt "当前路径？主区域有哪些文件？"
```

识图返回：窗口在 `D:\Github\claude-vision-skill`，文件列表 6 项。→ 需要先导航到桌面。

### 第 2 步：导航到桌面（推荐用"后退"按钮而非输入路径）

- 若窗口历史里有桌面：无障碍树里找 `后退`（Description 含"返回到 桌面"），`sky.click({ element_index })` 或按屏幕坐标点它
- **教训**：不要用地址栏输入路径的方式导航（`type_text` 会清空剪贴板；如果剪贴板里已有剪切内容会丢）

### 第 3 步：全选 + 剪切

1. 点文件列表区域，`Ctrl+A` 全选
2. 识图确认："已选择 10 个项目"
3. **点工具栏"剪切"按钮**（无障碍树里 Description 为"将所选项目移动到剪贴板"）
   - 教训：`Ctrl+X` 快捷键在焦点异常（停在地址栏）时可能完全无效；工具栏按钮永远可靠

### 第 4 步：验证剪贴板（观察，非操作）

```powershell
powershell.exe -NoProfile -STA -Command "Get-Clipboard -Format FileDropList | % { $_.FullName }"
```

确认 10 个桌面文件在剪贴板。

### 第 5 步：导航到 D:\（纯按钮）

- 点"前进"按钮（Description 为"前进到 本地磁盘 (D:)"）——刚才是从 D:\ 后退到桌面的，历史里就有
- 或点左侧导航树"本地磁盘 (D:)"（树项目可能无缓存边界，用坐标点击）
- **教训**：此时绝对不要用地址栏输入，否则剪贴板被清空

### 第 6 步：粘贴 + 等待

1. 无障碍树确认"粘贴"按钮可用（剪贴板非空时可用）
2. 点"粘贴"按钮
3. **等待 3~6 秒**再截图——移动有进度窗口，过早截图会误判失败

### 第 7 步：验证两端

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/see.ps1 -Prompt "当前文件夹路径？项目总数？是否有 clipboard_2026 开头的文件？"
```

- D:\ 根目录：21 → 31 项，含全部 10 个桌面项目
- 桌面：0 项（可"后退"回去再截图确认）

## 关键决策点速查

| 情况 | 做法 |
|---|---|
| 需要导航且历史可用 | 后退/前进按钮（最安全） |
| 需要输入路径导航 | 确认剪贴板无剪切内容后再 `Ctrl+L` + 输入 |
| 剪切/复制 | 点工具栏按钮，不用快捷键 |
| 粘贴 | 点工具栏按钮；等待进度窗口结束 |
| 焦点不确定 | 先点目标区域，再确认无障碍树 focused element |
| 右键菜单不弹 | 坐标可能落在非图标区；改点工具栏按钮或换元素索引 |

## 坑位记录（都是当天实测踩过的）

1. `Ctrl+X` 两次无效、剪贴板始终为空 → 改用工具栏"剪切"按钮，一次成功
2. 地址栏输入 `D:\` 后，剪贴板从 10 项变成空 → 剪贴板被输入过程清空；之后全部改按钮导航
3. 右键在图标区域不弹菜单（坐标估算偏） → 放弃右键，改工具栏按钮
4. 树项目 `element 26 has no cached bounds` → 树项目无法索引点击，改点有边界的按钮
5. 粘贴后立刻截图显示 21 项 → 其实正在移动，等 6 秒后 31 项全部到位
