# 文件资源管理器（Explorer）操作技巧

> 最后更新: 2026-08-05
> 验证方式: 实测（文件移动任务 + 新建文件夹/重命名任务，全程 UI 模拟）

## 入口与识别

- 窗口标题：`<路径> - 文件资源管理器`
- App 标识：`process:C:\Windows\explorer.exe`（sky list_windows 可查）
- 界面结构：标签页条 → 命令栏（新建/剪切/复制/粘贴/重命名/删除/排序/查看）→ 面包屑/搜索 → 左侧导航树 + 文件列表 + 右侧详细信息窗格

## 快捷键（优先使用）

| 功能 | 快捷键 | 验证状态 | 备注 |
|---|---|---|---|
| 聚焦地址栏 | `Ctrl+L` | ✅ 2026-08-05 实测 | 聚焦后输入路径回车即导航 |
| 全选 | `Ctrl+A` | ✅ 2026-08-05 实测 | 文件列表有焦点时有效 |
| 新建文件夹 | `Ctrl+Shift+N` | ✅ 2026-08-05 实测 | 需列表有焦点；焦点错位会打到别的应用 |
| 重命名 | `F2` | ✅ 2026-08-05 实测 | 配合 UIA 选中列表项 |
| 后退/前进 | `Alt+Left` / `Alt+Right` | 未实测（通用已知） | 工具栏按钮更可靠 |
| 刷新 | `F5` | 未实测（通用已知） | |
| 剪切/粘贴 | `Ctrl+X` / `Ctrl+V` | ⚠️ 2026-08-05 实测**不可靠** | 焦点在地址栏时无效；改用工具栏按钮 |

## 结构树要点（UIA 无障碍树）

- 工具栏按钮**有缓存边界，可索引点击**：剪切≈131、复制≈133、粘贴≈135、后退≈108、前进≈109（索引随界面变化，以当次观察为准）
- **左侧导航树项目（树项目）无缓存边界**，`sky.click(element_index)` 报 `element 26 has no cached bounds` → 用坐标点击或走按钮
- **列表项选中用 UIA**：模拟鼠标点击列表项（选中/右键）可能无效 → `SelectionItemPattern.Select()` 选中，再配键盘（F2 / Ctrl+Shift+N 等）（2026-08-05 实测）
- 焦点状态：`The focused UI element is 113 编辑 地址栏` → 导航后焦点常停在地址栏，快捷键会打错地方
- 窗口标题可能滞后于实际导航，以截图为准

## 常见坑位

- 地址栏 `type_text` 输入路径会**清空剪贴板**（2026-08-05 实测：剪切 10 个文件后输入 `D:\` 导航，剪贴板变空）→ 剪切后导航改用后退/前进按钮或点击左侧树
- 键盘 `Ctrl+X/Ctrl+V` 注入可能不生效（焦点问题）→ 优先点工具栏"剪切/粘贴"按钮（已验证一次成功）
- **模拟鼠标点击列表项不可靠**：现代资源管理器对模拟点击的选中/右键无响应（2026-08-05 实测）→ UIA `SelectionItemPattern.Select()` + 键盘
- **`Ctrl+Shift+N` 焦点错位**：会打到别的应用（在记事本=新建窗口，2026-08-05 实测）→ 操作前先确认焦点在列表
- 粘贴大文件有**进度窗口**，需等待 3~6 秒再截图验证，过早截图会误判失败
- 全选时若点击落点不对，Ctrl+A 可能作用于地址栏文本；点列表空白处后再按
