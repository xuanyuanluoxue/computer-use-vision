# 网易云音乐 PC（cloudmusic）操作技巧

> 最后更新: 2026-08-05
> 验证方式: 实测（播放《起风了》任务：输入方案已验证，结果页播放未完成）

## 入口与识别

- 窗口标题：`<当前歌曲> - <歌手>`（如 `いのちの名前 - 広橋真紀子`）
- **标题自动变化**：网易云自动播放/切歌，标题不断变化（2026-08-05 实测序列：いのちの名前→药到病除→The truth that you leave→一格格→Hit The Road Jack→Fire）→ 不能把标题当稳定锚点；重启进程会恢复播放状态
- App 标识：`{6D809377-6AF0-444B-8957-A3773F02200E}\NetEase\CloudMusic\cloudmusic.exe`；进程 `cloudmusic.exe`，路径 `C:\Program Files\Netease\CloudMusic\cloudmusic.exe`
- **多窗口**（2026-08-05 实测）：主窗口（大，标题为当前歌曲）+ 迷你播放器（小，标题"迷你播放器"）+ 桌面歌词。`Get-Process.MainWindowHandle` 可能返回小窗口 → 用 `EnumWindows` 按 pid 找面积最大的可见窗口
- 界面模式：主界面（左侧导航：推荐/精选/播客/漫游/关注 + 我的歌单；右上角搜索框）与**播放页**（大封面+歌词+评论，无侧栏无搜索框）两种

## 快捷键（优先使用）

| 功能 | 快捷键 | 验证状态 | 备注 |
|---|---|---|---|
| 聚焦搜索框 | `Ctrl+F` | ✅ 2026-08-05 实测 | PostMessage 直发大窗口有效；SendInput 未测 |
| 清空搜索框 | 退格 ×40 | ✅ 2026-08-05 实测 | PostMessage `Ctrl+A` 无效，用 `WM_CHAR` 退格(0x08) 代替 |
| 中文直输 | `WM_CHAR` | ✅ 2026-08-05 实测 | PostMessage 直发中文，绕过 IME |

## 已验证输入方案（PostMessage 直发大窗口，2026-08-05 实测）

1. `EnumWindows` 按 pid 找大窗口（标题含 ` - `）；若前台是"迷你播放器"先关闭它，或直接 PostMessage 发大窗口
2. PostMessage `Ctrl+F`（WM_KEYDOWN 0x11+0x46）→ 聚焦搜索框 ✅
3. PostMessage `WM_CHAR` 退格(0x08)×40 → 清空 ✅（`Ctrl+A` 无效）
4. PostMessage `WM_CHAR` 中文"起风了" → 绕过 IME ✅
5. PostMessage `Enter`(0x0D) → 提交搜索（进入结果页是否播放**待验证**）

## 结构树要点（UIA 无障碍树）

- 主界面搜索框：元素 `编辑`（索引约 191，内容为占位/历史项），旁边有 `按钮 search`（索引约 189）
- 播放页有 `图像 slide_up`（收起播放页按钮），但**无缓存边界**，无法索引点击 → 需要坐标或用户手动退出
- 播放页模式下结构树没有搜索框/侧栏元素

## 常见坑位

- **播放页模式**：点封面进入的播放详情页没有搜索框和侧栏（2026-08-05 实测）→ 先退出播放页（收起按钮/用户手动）再搜索
- **搜索框内容显示历史项**：点击编辑框会显示最近搜索/占位内容（如 `稳稳的幸福 - 陈奕迅`、`❤️opus - 坂本龍一`），容易误判为已输入
- **中文输入**：sky.type_text / SendInput 拼音方案不可靠（2026-08-05 实测）→ PostMessage `WM_CHAR` 直发已验证；剪贴板粘贴会占用剪贴板且需先清空
- **PostMessage 组合键部分失效**：`Ctrl+F` 有效、`Ctrl+A` 无效（差异 0）→ 清空用退格（2026-08-05 实测）
- **迷你播放器抢前台**：SendInput 键盘会打错地方 → 先关闭迷你播放器，或 PostMessage 直发大窗口
- **设置页误入**：误入设置页后 Esc/Alt+Left 均无法退出，需重启应用恢复（2026-08-05 实测）
- **vision 误判**：vision 模型在网易云上多次误判/编造内容 → 用像素对比（搜索框区域差异）验证，不要轻信描述
